## Introduction

This specification defines limits that separate supported behavior from research claims for [sdlm](../wiki.html#definition-sdlm).

## Core Content

The product must describe the installed [controlled language](../wiki.html#definition-cnl) as bounded and extensible. General-language understanding, automatic document extraction, autonomous curriculum generation, complete historical source and derivation [provenance](../wiki.html#definition-proof), incremental truth maintenance, distributed execution, and hard isolation require distinct implementations and evidence before they become supported claims.

A reference document pack demonstrates execution of authored document knowledge. It must not be presented as an automatic document ingestion system. [Circuit](../wiki.html#definition-semantic-circuit) counts and passing examples must not be used as proxies for broad intelligence, unseen-task generalization or production throughput.

Research evaluation should include unseen compositions, independently authored packs, noisy and adversarial language, ambiguity growth, [proof](../wiki.html#definition-proof) completeness, concurrency failure recovery, [session](../wiki.html#definition-session) version changes, and measured retrieval quality. [Hypotheses](../wiki.html#definition-hypothesis) and proposed mechanisms in the book must be clearly distinguished from executable mechanisms. Authoritative interface contracts take precedence over speculative research discussion.

Assumption-guided interpretation records actual decisions and supports corrective retraction. It does not establish calibrated confidence, general plausibility, broad linguistic coverage or autonomous [circuit](../wiki.html#definition-semantic-circuit) synthesis. Evaluation must measure incorrect accepted guesses as well as strict rejection rates and include independent correction scenarios.
